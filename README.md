# NWPU_YRCC_GFICE

This is the release repo for the code and dataset introduced in paper [River Ice Fine-Grained Segmentation: A GF-2 Satellite Image Dataset and Deep Learning Benchmark](https://doi.org/10.1109/TGRS.2025.3604644)

## Dataset
The dataset has been published on [HuggingFace](https://huggingface.co/datasets/ASGOLabMultisourceCooperationGroup/NWPU_YRCC_GFICE) under __Creative Commons Attribution Non Commercial Share Alike 4.0__ license.
